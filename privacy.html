プライバシーポリシー

  • 本ツールは作者本人の Google アカウントでのみ使用します。
  • Gmail は読み取り専用（gmail.readonly）で、チケット購入メールの内容を取得します。
  • Google カレンダーには、作者本人の予定の登録・更新のみを行います（calendar.events）。
  • 取得したデータは作者の PC 内にのみ保存し、第三者への提供や外部サーバーへの送信は行いません。
  • Google API から取得した情報の利用は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。
